## 2026-07-16 - Path Traversal Prevention in Terminal Launch
**Vulnerability:** In VS Code extensions that accept folder paths from webviews (or untrusted webview messages) to spawn terminals or files, arbitrary directory targeting or path traversal can occur if paths are not validated against the workspace boundaries.
**Learning:** Using `vscode.Uri.file(path)` can hardcode schemes and break on remote setups (like SSH or WSL), but validating native paths with platform-agnostic tools like `path.relative` against all active workspace folders (`vscode.workspace.workspaceFolders`) protects both local and remote environments.
**Prevention:** Always check if a user-supplied directory path is contained within the active workspace folders by verifying that `path.isAbsolute(folderPath)` and `!path.relative(workspaceFSPath, folderPath).startsWith('..') && !path.isAbsolute(path.relative(workspaceFSPath, folderPath))` hold true for at least one workspace folder. Show a warning message to the user and fall back safely if validation fails.
