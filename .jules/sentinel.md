## 2026-11-03 - Path Traversal Prevention in Terminal Launches
**Vulnerability:** The `launchNewTerminal` function accepted an arbitrary `folderPath` from webview messages (`openClaude`) and used it as the `cwd` when spawning a terminal running Claude Code without validating that the path belonged to the active workspace. A compromised webview or malicious message could launch terminals in sensitive host directories outside the workspace.
**Learning:** In VS Code extensions, webview message payloads must be treated as untrusted input. When validating paths against workspace folders across operating systems (including Windows with backslashes and remote URI schemes like SSH/WSL), comparing `path.relative` against active workspace folder `fsPath` attributes prevents path traversal without fragile URI string parsing.
**Prevention:** Always validate that incoming folder paths are contained within at least one active workspace folder (`!relative.startsWith('..') && !path.isAbsolute(relative)`) before passing them to `vscode.window.createTerminal`.
