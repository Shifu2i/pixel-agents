## 2026-07-16 - Path Traversal Prevention in Terminal Launch
**Vulnerability:** Insecure terminal working directory launch (Path Traversal/Workspace Escape). The extension webview allows the user to trigger `openClaude` message containing an arbitrary string `folderPath` which is subsequently passed directly as the `cwd` (current working directory) options to `vscode.window.createTerminal` without any validation. This allows launching terminal processes in arbitrary paths outside the current VS Code workspace folders.
**Learning:** In VS Code extensions, webview content is technically untrusted, and any incoming arguments (e.g. file paths, folder paths) sent via `postMessage` must be rigorously validated against workspace bounds before launching system shells or reading/writing files in those directories.
**Prevention:** Always perform platform-agnostic workspace boundaries checks using the native `path.relative` and `path.isAbsolute` methods to verify if a user-supplied directory path is strictly located within one of the active workspace folders (`vscode.workspace.workspaceFolders`). If validation fails, display a safe fallback warning and revert to a default safe workspace directory path.
