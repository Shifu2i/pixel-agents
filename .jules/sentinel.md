## 2026-10-31 - Path Traversal Prevention in Terminal Launches
**Vulnerability:** The webview handler for `openClaude` passes an arbitrary `folderPath` parameter to `launchNewTerminal`, which previously assigned it directly to the terminal's working directory (`cwd`) without verifying if it was inside an authorized workspace folder. An attacker or malicious webview script could trigger terminal creation in sensitive host filesystem locations outside the project workspace.
**Learning:** Checking paths across platforms in VS Code extensions requires handling both relative path boundaries and cross-platform path separators. Relying on `vscode.Uri` manipulations or naive path comparisons can fail on Windows due to drive letters and backslashes, or in remote workspaces.
**Prevention:** Use `path.relative` against each workspace folder's `fsPath` and ensure `!relative.startsWith('..') && !path.isAbsolute(relative)` to reliably verify directory containment before using untrusted folder paths in terminal creation or file operations.
