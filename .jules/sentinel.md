## 2026-11-11 - Path Traversal Prevention in Terminal Launches
**Vulnerability:** In `launchNewTerminal`, `folderPath` received from webview messages was passed directly as the terminal working directory (`cwd`) without validating that it resided within any of the active workspace folders.
**Learning:** Messages from VS Code webviews must be treated as untrusted input. If a webview is compromised, an attacker could attempt path traversal to launch terminals in arbitrary directories on the host. Furthermore, manipulating URIs directly can introduce cross-platform edge cases on Windows due to backslashes; comparing filesystem paths using `path.relative` and `path.isAbsolute` provides robust, cross-platform validation.
**Prevention:** Always validate user/webview-provided filesystem paths against `vscode.workspace.workspaceFolders` using `path.relative` and ensure the computed relative path does not start with `'..'` and is not absolute, falling back to a safe default workspace directory.
