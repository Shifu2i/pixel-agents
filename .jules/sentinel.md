## 2026-10-15 - Unvalidated Workspace Folder Path Traversal in Terminal Launch
**Vulnerability:** `launchNewTerminal` in `src/agentManager.ts` accepted a `folderPath` string parameter sent from webview postMessage (`openClaude`) and passed it directly as the `cwd` when creating a VS Code terminal. An attacker or compromised webview could send an arbitrary file system path (or relative path traversal like `../../..`), causing VS Code to open a terminal running in arbitrary directories outside the active workspace.
**Learning:** Webview message handlers must never trust incoming path parameters for backend file system operations or process execution environments. When validating paths against VS Code workspace folders, URI path manipulation can fail on Windows due to backslashes; using `path.relative(folder.uri.fsPath, folderPath)` and checking `!rel.startsWith('..') && !path.isAbsolute(rel)` provides reliable, platform-agnostic workspace containment validation.
**Prevention:** Always validate webview-provided paths against `vscode.workspace.workspaceFolders` before passing them as `cwd` or using them in file operations. Fall back to `workspaceFolders[0].uri.fsPath` with a warning message if validation fails.
