## 2026-07-16 - Path Traversal Prevention in Terminal Launch
**Vulnerability:** Path traversal via untrusted folder paths passed in webview messages. When launching a new terminal, the extension trusted any arbitrary string passed as `folderPath` and utilized it directly as the terminal's working directory (`cwd`). This allowed a potentially compromised or malicious webview to trigger a terminal launch in folders outside the active workspace.
**Learning:** In VS Code extensions, webviews run in a different execution context but can communicate via postMessage to perform privileged backend operations. Any input received from the webview, including filesystem paths, must be treated as untrusted. Standardizing on path containment checks using platform-agnostic `path.relative` is the most robust cross-platform way to validate filesystem inputs against active workspace folders.
**Prevention:** Always validate folder/file paths supplied by webviews or untrusted sources against active workspace folders (`vscode.workspace.workspaceFolders`) by verifying that the relative path resolved between the workspace folder and the target path does not start with `..` and is not absolute. Show a visible warning fallback instead of silent failure or insecure execution.
