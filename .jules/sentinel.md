## 2026-07-16 - Path Traversal prevention in launching terminals
**Vulnerability:** In VS Code extensions, launching a terminal using a user-provided or webview-provided path as the workspace/terminal working directory (`cwd`) can result in path traversal or terminal launches in arbitrary directories if the path is not strictly validated against the active workspace folders.
**Learning:** Simply resolving the path with `path.resolve` is not enough, as users or webview messages can specify paths outside of the workspace. Manipulating URIs via VS Code API's `.with({ path })` is also buggy on Windows due to native backslash differences. A platform-agnostic containment check using `path.relative` and `path.isAbsolute` is the safest way to ensure a path is contained within the active workspace.
**Prevention:** Always perform validation of any paths supplied by the webview by checking containment against all active workspace folders. Fall back to the default workspace folder and warn the user using `vscode.window.showWarningMessage` if an invalid path is supplied.
