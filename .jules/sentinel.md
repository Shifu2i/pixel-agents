## 2026-07-16 - Path Traversal Prevention in Terminal Launch
**Vulnerability:** Path traversal risks arose from webview messages when launching terminals using unvalidated `folderPath` values. If a malicious webview sent an arbitrary path on the system, the extension would launch a terminal with that path as the active `cwd`.
**Learning:** In VS Code extensions, webview contents run in a separate context but can post messages back to the extension host. Parameters passed in these messages (such as `folderPath` for `vscode.window.createTerminal`) must be validated against known workspace folders. Furthermore, using URIs to validate paths fails on Windows environments where native paths have backslashes, so platform-agnostic native path comparisons with `path.relative` and `path.isAbsolute` must be used instead.
**Prevention:** Always validate all paths supplied by webviews or other untrusted sources by performing platform-agnostic containment checks (via `path.relative` and `path.isAbsolute`) against the active workspace folders before executing terminal spawns or file system access.
